## 3 · 新定案：`act+0x50C` 是疲惫帧倒计时器（修正 P20/P46）


判读脚本实测 **斜率 −1.000 /帧**，外推归零帧 **9537**，与实测

⇒ **`act+0x50C` 是 f32 帧倒计时（初值约 4800 帧 = 80 秒 @60fps）**，
归零即结束疲惫、`t505` 2→3→0、`t508` 恢复到 800。

（写入初值）、`0xBD46C vmla.f32 s4,s0,s2 / vstr s4,[r0]`（每帧累减）。

**修正既有定案**：P20 §5 与 P46 从 Rise 侧推断「疲惫无固定时长、靠进食恢复
结束」——在 **GU 链 I 上不成立**。GU 至少这条强制疲惫是**固定时长计时器驱动**，

（P46 本就标 [U]），或 FSM 状态字不在 `+0x41`。**不影响本轮结论**——
`t505` 状态机 + `t50c` 计时器已提供完整、可观测的疲惫判据。
判读脚本已把「p+0x41 未见 >=5」从「游戏未播 Start」改为存疑提示，避免误读。

5. P33 的 `c0000005` 仍未归因；本场零异常。
