## 3 · 为什么状态字段没取到（两个 bug + 一个推断证伪）

1. **`mon+0xCAC4` 不是状态字**（旧结论作废）。实机值域：主怪恒为 `413(0x19D)`，另一对象为浮点位模式 `3FB2855B / 405C1F6E` 等且每帧变化。离线反汇编 `0xCEFEB8` 确实把 `0x19D` 同时写进 `+0xCAC4/+0xCAC8`；`0xD0CAD0..` 还写 `0x54/0x55/0x56/0x57`。`mon+0xCBF1` 同样是噪声值域（0/169/230/221/81/255），`act+0x518` 只出现 0/1、无 2（P10 与 P11 一致）。
2. **C 行配额被噪声吃光**：v40 每帧比较 `c4` 这个浮点，值一变就记；400 条配额在 `f=14564..15380`（816 帧）打光，之后到 `f=120300` 全场**再无一条状态记录**。
3. **盯错怪**：C 行只监控 `LAST_MON=0C220060`，而加权抽选 V 行最多的主怪是 `0C181390`（30 次）。

另外 `8_lite_check.bat` 用裸 `python` 调用，cmd 环境里不存在 ⇒ `lite_result.txt` / `lite_state_result.txt` 本轮只有一行 `'python' is not recognized`。已修为绝对路径。
