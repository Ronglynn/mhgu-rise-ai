## 2 · v62 新增两类只读行

**`AE` 行**（`forge_onUpdate` 每帧扫 8 个 mon 槽的 `mon+0x73E0`，变化才输出，`MAX_AE=600`/epoch）：
`f mon old new gap sel a st e1 t505 log`

- `old/new` = L1 动作类前后 u32；`gap` = 距上次变化的 forge 帧数；`sel` = 累计主轨抽选；`a` = 动作开始计数；`st` = 怒；`e1` = `+0x73E1`；`t505` = 疲惫状态字。
- 对应 W3 前置：`+0x73E0` 每次变化 + 帧号、`0xAFF40` 动作间隔、`sel` 同帧配对、暂停期 forge 帧漂移（大 `gap` 段）。

**`QX` 行**（`h_unify` 每次调用，`MAX_QX=800`/epoch）：
`f mon r1 r2 r3 p5 w0 w1 kind e1 dc t505 t518 t5e08 a1a8 a2c0 log`

- `kind` = `(a3==2 && a1==0) ? a2 : 0xFF`；`w0/w1` = `+0x73E0` 前后（prev 表语义）；
- `e1/dc` = `+0x73E1/+0x73DC`；`t505/t518/t5e08` = 疲惫/发怒/异常状态位；`a1a8/a2c0` = `0x75224` 体内分支输入的等价字段。
- 对应 W4 前置：kind 分布与频次、mode 分类（0 提交 / 2 action-end / 5 请求）、异常状态位与 kind 的交叉表、跨怪「攻击类/非攻击类」语义映射的输入。

**护栏**：所有读取逐级 `heap_ok` + 上界检查（`mon+0x7400`、`act+0x6000`）；`LAST73E0/LAST73F` 首帧只记录不输出；`AE_LOG/QX_LOG` 随 30000 帧 epoch 重置；零内存写入、零参数/返回值改写。选 `AE`/`QX` 是为不改动既有 `A`/`Q` 行格式（第一份报告仍由 `analyze_v38_log.py` 判读）。
