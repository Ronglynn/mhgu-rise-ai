## 2 · v61 交付

**探针设计**：仅 TABLE 型 mode `{4,14,21,22}` 的距离调用触发，逐级读：

```
tune = rd(a0+0x75EC)                 heap_ok + 范围检查
cnt  = rd8(tune+0xFA)                1..8（离线观测 1..6）
base = rd(tune+0x7C)                 heap_ok 且 base+16*cnt < HEAP_HI
row  = base + 16*slot
t0..t3 = rd(row+0/4/8/12)            f32 原始 u32 位输出
```

新增 **`ZT` 行**（每 slot 一行，`MAX_ZT=600`/epoch，`ZT_LOG` 随 epoch 重置）：
`f mon md ip blk ba tune cnt base slot t0 t1 t2 t3 log`。
`ba` = `rd8(blk+2)`（begin 首操作数），用于实机判定 slot 来源。

**护栏**：每级 null/范围检查，任一失败静默跳过；不缓存跨帧指针；不改 `original!` 返回值、不写游戏内存。`mon+0x7700` 单独上界检查（原 `mon_ok` 的 `0x2600` 覆盖不到 `+0x75ec`）。选 `ZT` 而非 `T` 是为了避开 v49 已有的 `T` 行状态事件与 `MAX_T/T_LOG` 命名冲突。

## 3 · W2 高保真完整实现设计（v62，待 ZT 实机闭环后落地）

### 3.1 关键结构性洞察：4 个阈值天然切成 5 档

`emc.md:54` 的 matcher 是 `distance <= threshold` 逐 case 顺序比较；`dttune` 每行 4 个递增 f32。因此距离轴被切成 **5 个区间**：

```
band0: d < t0        band1: t0 <= d < t1     band2: t1 <= d < t2
band3: t2 <= d < t3  band4: d >= t3（4 个 case 均不命中 → default）
```

⇒ **GU 的 4 阈值与 Rise 的 5 距离档天然一一对应**，不需要「4 档降采样到 5 档」的近似。这是本路线相对路线 A 的核心保真增益。判读时需验证 GU 的 case 0..3 是否确实按上述顺序绑定（emc.md 为 [C] 代码级，风险低）。

### 3.2 数据通路（全部零写入）

1. **距离块调用**：`dist_table_probe` 读到 `t0..t3`；用 ZP 已验证可解的 `sub+0x30..0x48` 算 3D/XZ 距离 `d`；按上式定 `band 0..4`。
   - 若 `a0+0x75ec` 链不可用 ⇒ **降级到路线 A**（用 `hit`/`ts` 作 case 索引分档），不中断抽选。
   - 若 ZP 几何不可用 ⇒ 用该距离块 matcher 自身的 `ret`/命中 case 反推 band。
2. **跨调用状态**：复用现有 `CMON`/`P_MON` 槽，按 `mon` 记录 `{band, f}`，设短时效（如 300 帧）防止跨区/换怪串味。
3. **op02 抽选**：`rise_weight_pick()` 增加 `band` 输入，按 `(st3, band)` 从 15 张形状表取形状，替换现有「三态 + k3/k4 混合」。形状候选不足 / `sw!=100` / 全套校验失败 ⇒ 原样返回 v60 行为。
4. **形状表**：`out/rise_band_shapes.json`（本轮已生成），含 Rust 常量片段 `BAND_SHAPE: [[u32;4];15]`，每池 rates 降序补零到 4、和恒 100。例：anger range5 `[70,20,10,0]` H=1.1568；tired range1 `[65,25,10,0]` H=1.2362。
5. **编译期开关** `W2_BAND_ENABLE`（默认 0），实机验收后置 1；`W2_PROBE` 保持 1 供诊断，成品化时一起置 0。

### 3.3 护栏与回退

- 表链 / 几何 / 槽位任一级失败 ⇒ 降级路线 A ⇒ 再失败 ⇒ v60 原样返回；**绝不写游戏内存、绝不改 `original!` 参数**。
- `MAX_ZT` 配额与 epoch 重置沿用；不缓存指针跨帧。
- 新增 hook 数 **0**（仍 6 个）；`W1_ALL=1` / `DRAIN_ENABLE=0` / `PROFILE_RELEASE=1` 不变。
- 回退链 `v61 → v60 → v59 → v58 → v57 → v56 → …`。

### 3.4 v62 验收判据

`ZT` 表链可读率、5 档分布是否覆盖全 5 区间、`wall/wnok` 与 `w3/w4/wt` 按 `(st3,band)` 分化、动作多样性/连段完整性、零 FATAL / 零 `c0000005`、`live=1 hub=15`、体感「输出窗口」是否改善（注：节奏本体仍属 W3，未实现）。
