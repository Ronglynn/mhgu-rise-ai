# P60 · 全量离线挖掘怪物距离档（替代跨怪实机采样）

## 0 · 结论

**能。** 游戏解包数据里已包含跨怪通用的距离档定义，无需为每种怪各跑一场实机。
离线一次抽取覆盖 **137 个 enemy arc / 8488 个距离 switch 块 / 119 只怪的 4 档 f32 阈值表**；
v60 单场实机只采到 **11 个运行时块、1 个怪种**（`sp=0020` → emid 32 → 轰龙 Tigrex）。
离线数据量约为单场的 **772 倍**，且天然跨怪。

剩余实机量取决于实现路线（§4）：按 case 索引分档只需 1 场验证；按物理阈值对齐还需 1 场基址锚定与 slot 确证。

## 3 · 运行时地址 ↔ 离线块的锚定

用 `blk - pos` / `ip - pos` 反推 entry 运行时基址，得到 2 个 `blk` 候选、1 个不同的 `ip-pos` 基址候选。
聚类结果：**单个基址最多只覆盖 1 / 11 个实机 ip**。
实机 ip 分落在 `0x1BF9xxxx` 与 `0x1C10xxxx` 两个脚本段，且 `0x0b|0,1,2,3` 在 `em032*` 内有 82 个同构块 ⇒ case 序列不足以唯一确定 `(sec,entry,pos)`。唯一收敛的例子是 `0x1BF907A0`（基址 `0x1BF90700`，对应 `em032_00/em032_04` s0/e6 的 `0x6a|5,2` 块）。

**结论：现有日志不足以完成基址锚定**；但这只影响「用物理阈值查表」的路线，不影响「按 case 索引分档」的路线（见 §4）。

## 4 · 结论：还需要多少实机

**不需要每种怪跑一场。** 离线已给出 137 个 arc 的全部距离块 case 序列与 119 只怪的 4 档阈值表，
跨怪覆盖在数据层已解决。剩余实机量取决于选哪条 W2 实现路线：

**路线 A（推荐，低成本）：按 case 索引分档。** 运行时用 `h_matcher` 的 `ret` 反推命中
case 索引（`hit`，0..3）作为档位，直接驱动 W1 的「状态 × 档位」形状。离线表证明
`0x0b|0,1,2,3` 结构在 2182 个块、跨 137 个 arc 共享 ⇒ 相对判据天然跨怪，
**不需要物理阈值、不需要脚本基址、不需要多怪实机**。剩余只需 1 场验证：
① `hit` 与档位的一一对应、② 疲惫态 `st3=2` 的档位样本（离线表无状态维度）。

**路线 B（高保真，工程量大）：按物理距离档对齐 Rise 5 档。** 需要把 dttune 阈值表
按怪种编译进插件（或运行时查表），并补齐 3 项实机/静态确证：
① 脚本基址锚定（`ZS` 行 / `cmd`+`ent`，把 `ip` 映射到 `(sec,entry,pos)`）；
② slot 选择（每怪 2~6 行阈值，`0x71164(ctx,slot)` 的 slot 由哪个 begin 参数决定，
离线表已存 `beginArgs` 但 GU 侧无代码级确证）；
③ 命中顺序与单位验证（`distance <= threshold`，用 ZP 3D/XZ 距离对照 1~2 个已知阈值）。
另需疲惫态样本。**即便路线 B，也不需要逐怪跑任务** —— 阈值来自静态表，
实机只是锚定与验证。

两条路线的共同未完成项：W2 档位加权本身尚未写入插件；W3 门控 / W4 12 处境 Hub /
领地争夺仍未实现；Rise 5 档几何阈值（`em131_00_range_data.user.2`）仍未抽取。

## 5 · 假设与边界（明确标注）

- **op→mode 映射**：5 个距离 op 取自 `emc.md §4` / `mhgu/emc.mjs OP_NAMES`；`0x16`/`0x6a` 是 v60 实机观察到的几何 switch，`emc.md` 未列其 mode，阈值构造标为 `UNKNOWN`，不臆测为 case×100。
- **0x0b 的 mode 4 有前提**：`emc.md:42` 注明仅当 begin 操作数为 0；离线表按默认 mode 记录并保留 `beginArgs` 供复核。
- **dttune 表定位**：`[[ctx+0x75ec]+0x7c]` 是 loader 后的运行时对象字段，不是文件偏移；本工具按「4 个递增 f32 + 2 字节对齐扫描 + 64B 内聚类」定位，三只怪与已知数值吻合，但聚类可能并入重复段，行数不等于语义 slot 数。
- **TABLE 型 case 操作数是表列号（0..3），不是物理距离**；物理值必须查 dttune 行。SCALE100 型才是 `case×100`。
- 18 只怪未抽到阈值行（多为无 range 区的小型怪/变体），其 `0x0b`/`0x57` 块暂不能换算成物理距离，需单独处理或标为不适用。
- 本轮**未改插件/NRO/部署/日志格式**，只新增离线工具与数据表。
