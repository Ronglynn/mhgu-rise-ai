## my-weapon-tree 模组中文化（MHGU Recomp）
- 模组本体是 AArch32 Rust 编译的 .nro（forge 插件），无本地化机制，UI 文本硬编码在 .rodata（0x844ad 起，NUL 结尾，首尾相接无空隙）。
- 关键发现：插件加载字体走 helper@0x77b4c -> bl 0x83cd0 (ImFontAtlas_AddFontFromFileTTF)，r2/r3 均为 0（font_cfg=NULL, glyph_ranges=NULL），即只生成 0x20-0xFF 拉丁字模；GameFont.ttf 也只含拉丁字形。
- 方案：155 条字符串原地等长替换（中文+NUL+空格填充，不改长度不改指针）；在 NRO 头部 0x54 处写入 28 字节 ARM 跳板，重定向 0x77b78 的 bl，使 r3 指向自建字模范围表（0x52a700，330 段，0x20-0xFF + 所用汉字）；字体换成 simhei.ttf。
- 产物：mods/my-weapon-tree/（已替换）、备份在 MHGU 根目录 my-weapon-tree-backup-en/、脚本 wt_zh_table.py / wt_patch.py、说明 README-中文.txt（在模组目录）。
- 未验证项：需重启游戏实测；若界面仍未中文，需在模组设置里打开“使用游戏自带字体”。ImWchar 若为 32 位则范围表会失效（未确认）。
